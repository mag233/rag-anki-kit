# 个人知识库与学习助手

[English version available in README.md](README.md)

---

## 关于本项目

<p align="center">
  <img src="assets/intro.png" alt="Project Introduction" width="400" height="400"/>
</p>

**RAG Anki Kit** 是一个综合性的AI驱动研究助手，将您的学术论文和文档转化为智能知识管道。从高级文档摄取到复杂的知识图谱生成，从语义搜索到自动化闪卡创建，这个工具包以尖端的AI能力简化了整个研究工作流程。

这个项目代表了探索AI和自然语言处理激动人心世界的旅程，具有高级实体优化、增量处理和综合分析功能。基于对学习和研究效率的热情而构建，它集成了多种尖端技术，通过性能优化和模块化架构创造了无缝的学术研究体验。
---

## 🛠 技术栈与架构

本项目集成了现代AI和Web技术，具有高级优化：

- **🐍 Python**：具有模块化组件架构的核心后端逻辑
- **🌊 Streamlit**：具有自定义样式的交互式Web应用程序框架
- **🤖 OpenAI API**：GPT-4驱动的文本分析、摘要和高级实体提取
- **📊 ChromaDB**：具有智能缓存的语义搜索和嵌入向量数据库
- **🧮 NumPy/Pandas**：优化的数据操作和分析
- **🕸️ NetworkX**：高级图分析和知识网络构建
- **📈 Plotly + Pyvis**：交互式数据可视化、网络图谱和分析仪表板
- **🔧 Sentence Transformers**：用于实体优化的可选语义相似性
- **📄 PyMuPDF/Unstructured**：支持多格式的高级文档解析
- **⚡ 性能优化**：组件缓存、批处理和状态管理
- **🎨 CSS/HTML**：具有现代UI组件的自定义响应式设计
- **🌍 多语言**：具有语言感知处理的完整双语界面（英文/中文）

## ✨ 核心功能

### 🔍 **高级RAG（检索增强生成）**
- **智能文档处理**：支持PDF、Word文档、Excel文件、Markdown和HTML的高级解析上传
- **灵活分块策略**：基于句子、段落、页面或自定义长度的分割
- **智能向量数据库**：ChromaDB驱动的语义搜索与嵌入优化
- **交互式问答**：提出研究问题，获得带有来源引用的上下文答案
- **健康检查仪表板**：实时监控文档处理状态和嵌入覆盖率
- **模块化架构**：基于组件的设计优化性能，具有缓存功能

### 📚 **增强文献综述助手**
- **AI驱动查询优化**：自动改进研究问题以获得更好的检索效果
- **自动化摘要**：从您的文档集合生成综合文献摘要
- **引用管理**：自动提取和格式化参考文献
- **研究差距分析**：识别知识差距和研究机会
- **相关性过滤**：可配置的置信阈值确保结果质量
- **多语言支持**：使用双语界面处理多种语言的文档

### 🧠 **LitMap：高级知识图谱生成**
- **AI驱动的实体与关系提取**：GPT-4驱动的提取，支持8种实体类型和8种关系类型
- **两阶段实体优化**：
  - **阶段1**：语言规范化（始终启用），包括缩写扩展和单数化
  - **阶段2**：使用sentence transformers的语义相似性检测（可选）
- **增量处理**：智能逐块处理，具有进度跟踪和状态持久性
- **高级处理模式**：完全重处理、选择性重处理和增量更新
- **交互式可视化**：具有物理模拟和可定制布局的动态网络图
- **综合分析仪表板**：
  - 实体影响力评分和中心性分析
  - 最连接实体的详细关系分析
  - 置信度指标和处理统计
- **导出功能**：以多种格式保存图谱（GEXF、GraphML、JSON、图像）
- **成本估算**：实时OpenAI API使用跟踪

### 🎯 **智能Anki集成**
- **AI优化查询处理**：自动查询增强以获得更好的卡片生成
- **自动化闪卡生成**：从您的研究中创建Q&A和填空卡片
- **可配置难度和详细级别**：根据您的学习需求调整卡片复杂性
- **高级卡片预览**：增强的表格显示，支持文本换行和滚动
- **批量导出**：几分钟内生成数百张卡片，支持CSV下载
- **间隔重复就绪**：无缝导入Anki以优化学习

## 📖 使用指南

### 1. **RAG标签页** - 文档处理与智能问答
- **项目管理**：创建和切换多个研究项目
- **文件上传**：支持PDF、DOCX、Excel、Markdown和HTML文件
- **智能预处理**：根据文档类型和研究需求配置分块策略
- **健康检查仪表板**：监控处理状态、嵌入覆盖率和系统健康
- **向量数据库**：生成嵌入并进行增量更新和优化
- **智能搜索**：通过AI驱动的查询优化提问并获得引用答案

### 2. **文献标签页** - 高级研究综合
- **查询增强**：AI驱动的研究问题优化，以获得更好的检索效果
- **综合评述**：同时从多篇论文生成文献综述
- **引用分析**：提取关键发现、研究趋势和书目信息
- **相关性控制**：可配置的置信阈值确保结果质量
- **导出选项**：格式化的参考书目和研究摘要

### 3. **LitMap标签页** - 知识图谱生成与分析
- **步骤1**：选择具有健康状态指示器的已处理项目
- **步骤2**：配置高级优化选项的提取设置：
  - 实体置信阈值和去重
  - 两阶段优化（语言+语义相似性）
  - 自定义实体和关系类型
  - 启用物理的可视化
- **步骤3**：从8种预定义实体类型和8种关系类型中选择，或添加自定义类型
- **步骤4**：使用多种处理模式生成知识图谱：
  - **增量**：仅处理新块，保留现有数据
  - **选择性**：重新处理选定的块并具有合并功能
  - **完全重处理**：从头开始完全重新生成
- **步骤5**：探索交互式可视化和综合分析：
  - 具有物理模拟和可定制布局的网络图
  - 实体影响力评分和中心性分析
  - 具有关系多样性指标的最连接实体
  - 具有处理洞察的统计仪表板
- **步骤6**：以多种格式导出（GEXF、GraphML、JSON、PNG）

### 4. **Anki标签页** - 智能闪卡创建
- **AI查询优化**：增强学习查询以获得更好的卡片生成
- **可配置生成**：调整难度、详细级别和卡片数量
- **高级预览**：增强的表格显示，支持文本换行和综合格式化
- **多格式卡片**：从您的知识库生成Q&A和填空卡片
- **批处理**：高效创建和导出数百张卡片
- **直接导入**：无缝CSV导出以便Anki集成

## 🚀 快速开始

### 环境要求
- Python 3.8+
- OpenAI API密钥

### 安装步骤

1. **克隆仓库：**
   ```bash
   git clone https://github.com/mag233/rag-anki-kit.git
   cd rag-anki-kit
   ```

2. **安装依赖：**
   ```bash
   pip install -r requirements.txt
   ```

3. **配置OpenAI API密钥：**
   ```bash
   # 在项目根目录创建.env文件
   echo "OPENAI_API_KEY=your_api_key_here" > .env
   ```

4. **启动应用：**
   ```bash
   streamlit run src/app.py
   ```

5. **打开浏览器**并导航到 `http://localhost:8501`
